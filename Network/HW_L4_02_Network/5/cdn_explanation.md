# What is CDN

CDN stands for Content Delivery Network.

It is a distributed network of servers that delivers content faster to users.

---

# How CDN Reduces Latency

CDN stores cached content on edge servers close to users.

This reduces distance and improves loading speed.

---

# Edge Server vs Origin Server

## Origin Server

Main server where original content exists.

## Edge Server

Cache server near users that delivers cached content.
